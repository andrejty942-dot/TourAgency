### 3. Визуальная индикация ошибок (красная подсветка)

**Реализовано:**
- При ошибке валидации поле становится красным (фон + рамка)
- При начале ввода цвет автоматически сбрасывается на белый
- Все неправильные поля подсвечиваются одновременно

**Цвета:**
```csharp
// Ошибка
Background: IndianRed (#CD5C5C)
BorderBrush: DarkRed (#8B0000)

// Нормальное состояние
Background: White (#FFFFFF)
BorderBrush: #ABABADB3 (серый)
```

**Метод сброса цвета:**
```csharp
private void ResetFieldColor(object sender, TextChangedEventArgs e)
{
    var textBox = (TextBox)sender;
    textBox.Background = new SolidColorBrush(Colors.White);
    textBox.BorderBrush = new SolidColorBrush(Color.FromRgb(171, 173, 179));
}
```

**Подключено в XAML:**
```xml
<TextBox x:Name="TxtClientFio" TextChanged="ResetFieldColor"/>
```

### 4. Улучшенная логика валидации с накоплением ошибок

**До изменений:**
- Проверка останавливалась на первой ошибке
- Пользователь видел только одну ошибку за раз
- Нужно было исправлять по одной

**После изменений:**
- Проверяются ВСЕ поля без остановки
- Все неправильные поля становятся красными одновременно
- Одно окно со списком всех ошибок

**Пример сообщения:**
```
Ошибка валидации

• Введите название тура
• Введите страну
• Введите корректную длительность (целое число больше 0)
• Введите название гостиницы
```

**Реализация:**
```csharp
private void BtnAddClick(object sender, RoutedEventArgs e)
{
    bool hasErrors = false;
    string errorMessage = "";

    // Сброс цветов всех полей
    TxtName.Background = new SolidColorBrush(Colors.White);
    // ... остальные поля

    // Проверка каждого поля
    if (string.IsNullOrWhiteSpace(TxtName.Text))
    {
        TxtName.Background = new SolidColorBrush(Colors.IndianRed);
        TxtName.BorderBrush = new SolidColorBrush(Colors.DarkRed);
        errorMessage += "• Введите название тура\n";
        hasErrors = true;
    }
    // ... остальные проверки

    // Показ всех ошибок сразу
    if (hasErrors)
    {
        MessageBox.Show(errorMessage.TrimEnd('\n'), 
            "Ошибка валидации", 
            MessageBoxButton.OK, 
            MessageBoxImage.Warning);
        return;
    }

    // Сохранение данных...
}
```

private void Loadedwin(object sender, RoutedEventArgs e)
